## Microsoft AzOps

Adopt or improve a Git-based operating model for Azure with [Microsoft AzOps](https://github.com/Azure/AzOps). AzOps represents Azure resource hierarchy in a repository and supports pulling existing resources into source control and deploying ARM templates or Bicep across Azure scopes.

I can help with solution design, repository structure, deployment workflows, governance controls, and team enablement so that Azure changes are reviewed, repeatable, and manageable at scale.
